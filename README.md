# Flask To-Do List App

A simple To-Do List web application built with Flask and SQLite.  
Allows users to add, complete, and manage tasks with a sleek tile-based interface.

## Features

- Add tasks with title, description, and due date
- Tile-based task display (1/3 width tiles)
- Checkbox to mark tasks as completed (removes task from view)
- Overdue tasks highlighted in red
- Uses Flask and SQLAlchemy for backend
- Bootstrap 5 for responsive styling
